# 文本编辑（Text Edit）

一个**单文件**的文本编辑 / 排版 / 翻译 / 导出工具，同时提供 Android 安装包（APK）。

- `index.html`：全部功能都在这一个文件里（HTML + CSS + JS 全内联），用浏览器直接打开即可使用。
- `文本编辑.apk`：把上述网页封装进 Android WebView 的安装包，安装后手机上可当作独立 App 使用。

## 功能简介

- **文本编辑**：正文输入、字号/颜色/对齐等基础排版。
- **排版**：页面尺寸、边距、行距等版式设置。
- **图片**：导入图片、缩放（图片大小）、透明度、混合模式（正常 / 正片叠底 / 滤色 / 变暗 / 变亮 / 差值 / 排除 / 强光 / 线性光）、图层显隐、批量删除（默认全选，点图取消）。
- **文案存档**：把常用文案保存到本地，支持**导出**（`文案存档.json`）与**导入**；导入时同名覆盖、无正文自动过滤。
- **翻译**：内置腾讯 / 谷歌翻译通道，支持长文分段、进度可见。
- **导出**：导出当前排版为图片（Android 落盘到「相册 → 文本编辑」，浏览器落盘到下载目录，均会提示保存位置）。

## 使用方法

### 浏览器（电脑 / 手机）
直接双击或用浏览器打开 `index.html` 即可。无需联网（翻译功能需联网）。

### Android 手机
1. 把 `文本编辑.apk` 传到手机并安装（首次安装需允许「未知来源」）。
2. 打开 App，默认进入「编辑」模块；底部可切换 编辑 / 排版 / 背景 / 页眉页尾 / 导出。
3. 图片、文案存档等数据保存在 App 私有目录，退出不会丢失，需手动删除。
